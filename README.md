# 👨🏻‍💻 João Vitor Alves Brandão

**`Data Engineer | Big Data | Spark & Python`**

Sou **Engenheiro de Dados**, com forte experiência em **Apache Spark e Python**, atuando no desenvolvimento de **pipelines de dados escaláveis**, arquitetura de dados e soluções de **Big Data**.  
Trabalho desde a ingestão e transformação de grandes volumes de dados até sua disponibilização para **Analytics, Data Warehouse e Machine Learning**, sempre com foco em **performance, automação e governança**.

Tenho também experiência no desenvolvimento de **APIs e microserviços com Node.js**, criação de **esteiras CI/CD para dados**, deploy de jobs em plataformas de Big Data e conhecimentos complementares em **front-end com Angular**.
